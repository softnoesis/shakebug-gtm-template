# Shakebug Web SDK — Google Tag Manager Template

The official Google Tag Manager (GTM) community template for **[Shakebug](https://www.shakebug.com)** — comprehensive bug reporting, screen recording, and crash monitoring for web applications.

## Features

- **Visual Bug Reporting**: Screen capture with drawing tools for quick annotations.
- **Screen Recording**: Capture user actions, navigation, and audio for crystal-clear bug reproduction.
- **Automatic Crash Reporting**: Auto-captures unhandled JavaScript errors and console logs.
- **Zero-Code Setup**: Deploy Shakebug across your entire site in seconds via Google Tag Manager.

## Installation via GTM Community Template Gallery

1. In your Google Tag Manager container, navigate to **Templates** > **Tag Templates** > **Search Gallery**.
2. Search for **Shakebug Web SDK**.
3. Click **Add to Workspace**.

## Configuration

1. Create a new Tag and select **Shakebug Web SDK**.
2. Enter your **Shakebug App Key** from your [Shakebug Dashboard](https://www.shakebug.com).
3. Choose your configuration:
   - **Show Floating Feedback Button**: Toggle the floating feedback widget (Default: checked).
   - **Enable Crash Reporting**: Automatically capture unhandled JS errors (Default: checked).
4. Add a Trigger: **Initialization - All Pages** (or **All Pages**).
5. Save and Publish your GTM container.
